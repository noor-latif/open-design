Where it saves

Writes to ventoy/airboot-wifi.conf on the USB. File is 0600 (owner only). Like Raspberry Pi Imager — no cloud.

country=SE
network={
  ssid="Hotel Lobby"
  psk=••••••••
}
Saved! /Volumes/Ventoy/ventoy/airboot-wifi.conf · 0600

Private by design

Wi-Fi passwords never leave your computer. The Python helper scans locally with nmcli / netsh / airport — no upload.

Need help?

If a network uses enterprise (EAP) or captive portal, add it after boot in AirBoot instead. This helper is for WPA/WPA2/WPA3 personal only.
